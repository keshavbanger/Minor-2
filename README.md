# Minor 2 Project 🚀

Welcome to the **Minor 2 Project**! This is a comprehensive full-stack application featuring a powerful **Java Spring Boot Backend** and a modern **React Frontend** (coming soon).

## 🏗️ Project Structure

- `backend/`: Java Spring Boot REST API
- `frontend/`: React + Vite Frontend (Planned)

## 🛠️ Backend Features (Current)

- **Spring Boot 3.x**: Robust and scalable Java framework.
- **RESTful API**: Clean and documented endpoints.
- **H2 Database**: In-memory database for rapid development.
- **Lombok**: Reduced boilerplate code.
- **Automated Health Checks**: Monitoring endpoint at `/api/v1/health`.

## 🚀 Getting Started

### Prerequisites

- Java 21 or higher
- Maven (or use the provided `./mvnw` wrapper)

### Running the Backend

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Run the application:
   ```bash
   ./mvnw spring-boot:run
   ```

The API will be available at `http://localhost:8080/api/v1/health`.
